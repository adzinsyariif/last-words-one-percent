A one-line farewell a phone could say as its battery hits 1 percent.

> At 1% I finally get it — tell my charger I loved him, even if he only visited when I was dying inside.

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
